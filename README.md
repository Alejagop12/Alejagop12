## 📌 Field note

> While training junior BAs on patient-intake automation for a large healthcare provider, the biggest risk wasn't technical. It was **not knowing who owned each blocker**.
> We introduced a **"blocker board"** with named owners for system, data and policy issues, which cut average blocker resolution time by **over 40%** and sped up bot deployment.
>
> Lesson: before automating a process, define **ownership, governance and escalation paths**. Otherwise you are just automating chaos.
